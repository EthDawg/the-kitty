# Pack

A pack is a handover: a question, a scope, lines, evidence links, gaps. One data shape, however it renders. Tax is the first instance, and [`lender.js`](lender.js) is the second.

```bash
node standard/world/build.js                                                      # the Davies world
node src/household/pack/cli.js tax --person JORDAN --fy FY2024 --as-of 2024-08-05 --out out
node src/household/pack/cli.js takeback --person MIA --fy FY2023 --as-of 2023-08-05 --back 2024-03-31 --out out
node src/household/pack/cli.js kit --fy FY2026 --out out
node --test src/household/pack/test.js
python3 src/household/pack/test_independent.py                                    # needs soffice, openpyxl, pypdf
```

Every file here but `node-host.js`, `cli.js` and the tests is plain JavaScript and runs in a page through a host of four calls: `readSource`, `sha256`, `deflateRaw`, `inflate`.
A test runs the whole thing in a bare context with no Node and gets the same bytes. `deflateRaw` is optional: without it a zip is stored, and is still a zip.

| File | What it does |
|---|---|
| `pack.js` | The shape and its promises. `validate` throws on a bare zero, a number on a missing value, a nil with no basis, or a link. |
| `tax.js`, `evidence.js` | The tax instance. Reads the engine's result, walks each figure to its files, finds the gaps. Computes no tax. |
| `lender.js` | The second instance, on purpose small. |
| `workbook-tax.js` | The template's tabs, with evidence on every line. |
| `workbook-generic.js` | Any pack as a plain workbook. |
| `bundle.js` | The zip: workbook, evidence, cover note, manifest, the tax file number gate, splitting. |
| `takeback.js` | Sets what was lodged beside the draft, and returns a new version. |
| `blank.js` | The kit a stranger gets, through the same renderer. |
| `xlsx.js`, `formula.js`, `zip.js`, `pdf.js`, `tfn.js` | Small writers and readers with no platform calls. |

## Decisions taken without asking

- **FY2024 is the tricky year.** A second rental bought mid-year in one name, shares and crypto sold, an amendment to the year before landing inside it.
- **As of 5 August 2024.** Every statement is in and the return is not yet lodged, so take-back has something to do. The clock filters originals by the day they were held.
- **A value is one of four things:** a number, `nil` with a stated basis, `not_found`, or `not_asked`. There is no other way to write 0.
- **The second instance changed the shape.** Scope holds people and a period, not a person and a year, and a line can be a balance true on a date. Tax lines read as before.
- **The evidence folder holds what proves the line, not everything.** An income statement goes in, not 26 payslips, unless payslips are all there is. A person's zip holds nothing of their spouse's alone. A joint statement is in both.
- **15 MB a part.** A 15 MB file is about 20 MB once mail encodes it, and 20 to 25 MB is where common mail services stop. Set `limit` to change it.
- **A file that cannot be read is held back.** A missed tax file number cannot be taken back, and one held-back file is an open item. A person can clear a file by its hash.
- **The workbook keeps to the engine.** Where the records show money the engine put on no label, the sheet says `not found` and raises it. It does not correct the engine in a spreadsheet.
- **Names are data.** See [`FINDINGS.md`](FINDINGS.md).
- **An example is rebuilt in a test.** `docs/examples` is generated by `cli.js examples`, and CI compares what it makes with what is committed, file by file.
