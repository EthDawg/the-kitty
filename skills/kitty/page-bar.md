# The page bar

What a household money page has to do. Each line came from a real round of changes on a real Kitty page (35 published versions, then the public edition), so a new page can start where those rounds ended.

## Say the answer first
1. Open with one verdict line that answers "how are we going?" (for example "On track", "Mostly on track", "Worth a look") and the reason in a few words.
2. Under it, at most four things that need a person, most serious first: failing or review checks, a goal falling short, a bill or renewal soon, spending well over the usual pace. Nothing else competes with them.
3. State progress toward a goal as money: "$26.9k of $30k", "$3.1k to go". A bar can carry the share; words carry dollars.

## Every number can be trusted
4. Tap any headline number to see what it is made of: the rows or parts that add up to it and the tab it came from.
5. Anything estimated (tax forecasts, projections) says so beside the number. Never present an estimate as confirmed.
6. Show the as-of date of the data, and say plainly when the month is not closed or a check is failing.
7. Never show internal IDs (account IDs, category IDs, metric IDs, transaction IDs) to a reader. Use the names.

## It survives bad data
8. If a tab is empty (for example no transactions yet), say so in words ("No transactions yet") instead of showing $0 as good news.
9. If one part fails to draw, that part says so and the rest of the page still works.

## It is calm on every screen
10. Works at 390px phone width with no sideways scrolling and nothing lost: lists stay lists, numbers are not cut off.
11. Light and dark themes are both designed, following the device setting.
12. Repeated items (cards, rows, chips) share the same padding, height rules and alignment. Nothing jumps or reflows after the page has loaded.
13. Money is in dollars with tabular figures so columns line up. Large figures are shortened on small tiles ($26.9k).
14. Each spending category keeps one colour everywhere it appears.
15. A drawer or pop-up is a proper dialog: focus moves into it, Escape closes it, focus returns to what opened it.
16. Motion is gentle and stops under reduced-motion settings.

## It stays honest about what it is
17. The page reads the sheet and never changes it.
18. One headline per card, plain words, no tiny print.
