# Tax pack

Use this for "build the FY26 tax pack" or "get the tax year ready for the accountant". The output is a Drive folder that one Download turns into a single zip. Run `coverage.md` first, so the pack says what is missing.

## Make the pack
1. Make a folder next to the household's tax records, named `FY26 tax pack`, with a subfolder `Sources`.
2. Copy each source for the year into Sources, prefixed with its record ID:
   - income statements, payslips, rental statements, loan interest statements, depreciation schedules;
   - receipts for deductions, donation receipts;
   - notices of assessment, ATO correspondence.
   Copy; never move or delete an original.
3. Write an index document in the folder:
   - who, and which period;
   - each person's figures from Tax Returns or Tax Forecast, with the result written as "refund" or "to pay";
   - the sources grouped by kind, each linking its copy and its original;
   - open items and anything coverage found missing;
   - the line "Open Sources, choose Download, and Drive makes one zip."
4. Put the folder link in Tax Returns, in the Pack column, for each person that year.

## Rules
- Ask before sharing the folder with anyone. A pack holds tax file numbers and income.
- Estimates say so. A lodged year uses the notice of assessment, not the estimate.
- Not tax advice.
