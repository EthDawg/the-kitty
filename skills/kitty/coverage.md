# Coverage: before you trust a year

The Kitty's coverage check. Run it for each person and each financial year before any number is used.

1. List every kind of income and deduction the person had last year (the last return) and every kind this year's evidence shows (bank deposits and payments, emails, notes).
2. For each, name the document that proves it. Mark it Found (file), Found elsewhere (file, and where it was hiding), Missing (what it is and where to get it), or Not needed (why).
3. Every account's statements run unbroken across the year. A gap is Missing.
4. Every sale (shares, crypto, property) has both a sale record and a purchase record. A sale without a purchase record is Missing.
5. Every number in a summary someone made (sheets, slides, notes) is checked against its source before it is used. A difference is a Conflict, and the source wins.
6. Say where anything found in only one place was found.
