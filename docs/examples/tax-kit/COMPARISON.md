# The kit, then and now

Draft. Nothing here is posted anywhere. This was written from a description of the earlier kit, not a reading of it, so check the middle column against the kit itself before anyone uses this.

The earlier public kit was a 5 KB sheet for Person A and Person B, with a workflow template. It was a good idea in a small form. This is what a stranger gets now.

| | The earlier kit, as described | This kit |
|---|---|---|
| **The sheet** | A 5 KB shell | The tabs an accountant reads: Return Summary, Income, Shares, one per property, Loan Interest, Tax Estimate, Open Items, Evidence, Prior Years |
| **Who it is for** | Person A and Person B together | One return per person, because that is what gets lodged. A joint property is entered once, in full, and a share is applied once |
| **Labels** | To check | Tax return labels, in return order, with whole dollars as they go on the return |
| **A number you did not type** | To check | Live formulas, in black. What you type is in blue |
| **An empty cell** | To check | Says `not found`, and the total above it says Incomplete. Confirmed nil is a different answer |
| **Loan interest** | To check | Every loan, deductible or not, reconciled to a difference that must be zero |
| **Rental costs** | To check | Agent-paid and paid directly kept apart, reconciled to the agent's own money out |
| **Shares** | To check | The employee share discount kept apart from capital gains, by parcel, losses before the discount |
| **Where a figure came from** | To check | The file and page or row beside every figure |
| **What is left** | To check | Open Items: what you still owe, split from what is left to the accountant |
| **Tax tables** | To check | Rates in force for the year, on the sheet, read by date from a reference that says how far each row has been checked |
| **What the agent does** | A workflow template to follow | A [skill](../../../skills/kitty-tax-pack/SKILL.md) your own agent can run, with the limits stated: it prepares, it does not lodge, and a tax file number never goes in the pack |
| **After lodging** | To check | The return comes back as evidence and is set beside the draft. An amendment is a new version, and the old one stays |

## What it still is not

It is a sheet. By hand it is as good as the person filling it in. The file links, the `at risk` marks and the zip come from running the pack over a Kitty, and [`tax-pack/`](../tax-pack/) shows what that looks like. It has been read by LibreOffice and tested on invented families. No real accountant has opened it yet.

Not tax advice.
