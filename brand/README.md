# The Kitty brand kit

The artwork is hand-drawn SVG, generated by `build_brand.py`, so the source of truth is the Python file and the
SVGs are its output. Run `python3 brand/build_brand.py` after editing it; open `brand/index.html` to see the whole
kit in light and dark with the motion pieces live.

**Cat is the default.** The lucky cat (a maneki-neko) raises one paw to beckon good fortune and rests the other on a
lucky coin. Households that would rather have a dog switch to the dog set, a shiba with the same calm face; nothing
else about the page changes. `cat/` and `dog/` carry the same files so the `mascot` field in `tokens.json` can swap them. It chooses the illustrations, fortune cookie or biscuit, and primary iOS app icon for both builds. The other icon is offered under Setup → Appearance on iOS.

Edit theme values in `brand/tokens.json` and run `python3 brand/generate_tokens.py`. This writes the shared page CSS and native Swift colours; the Xcode resource preparation takes its launch colours and icons from the same sources. For a semantic icon change, edit the drawing in `build_brand.py` and run `python3 brand/build_brand.py --icons-only`. CI checks the generated files and rebuilds both hosts after a temporary colour, icon and mascot change.

| Asset | Where | Use |
|---|---|---|
| Mascot | `cat/mascot.svg`, `dog/mascot.svg` | Hero, onboarding, empty states, the trust drawer. 160 grid; colours are CSS variables (`--mascot-*`) with fallbacks, so they follow the page's accent if you want them to |
| App icon | `cat/app-icon.svg` and PNGs at 16 to 1024, same for `dog/` | Portals, README, any host that lets you set an icon (claude.ai generates the artifact's own icon from the `icon` word) |
| Icons | `icons/*.svg`, `icons/sprite.svg`, `icons/icons.json` | 95 icons on a 24 grid, stroke 2, round caps, `currentColor`. `icons.json` says what each one means; the ids are `i-<name>`, the same scheme the page already uses |
| Empty states | `illustrations/<set>-<scene>.svg` | `empty-activity`, `all-reviewed`, `empty-goals`, `connect-sheet`; colours come from the page tokens |
| Motion | `motion/motion.css`, `motion/motion.js`, `fortune-cookie.svg`, `biscuit.svg`, `coin.svg`, `note.svg` | See below |

## Semantics that matter

Superannuation is a nest egg, not a bank. Self-managed super is the nest egg you hold the key to. An investment
property has a "for lease" sign; a loan has a percent sign on the house; an offset account is money sinking into the
house. Vesting employee shares are a padlock with a clock. Crypto is a hexagon. A car is a car and a laptop is a
laptop. Categories use the object a person recognises (a basket, a fork and knife, a pump, a paper plane), never an
abstraction.

## When motion happens, and when it never does

Motion is finite, it follows an event, and it is a no-op under `prefers-reduced-motion` (the fortune slip still
shows its text).

- `KittyMotion.beckon(el)`: the cat beckons once. Good news only: a goal reached, a month closed, an import landed.
- `KittyMotion.wag(el)`: the dog wags twice, the dog set's equivalent.
- `KittyMotion.rain()`: coins and notes fall for about two seconds. Money milestones only (a goal reached, a loan
  paid down past a round number). It replaces confetti for money moments; confetti stays for the one-time welcome.
- `KittyMotion.fortune(btn, text, onOpen)`: a fortune cookie (the dog set's biscuit) that cracks on tap to reveal one
  line. This is how the Kitty proposes and a person decides: in Review, a row with no rule shows a closed cookie;
  cracking it shows the proposed merchant and category with "Make it a rule". In Ask, the note's one novel insight
  arrives as a cookie. One cookie per row or note, never opened on load, never more than one on screen.

Nothing animates on page load. The entrance motion the page already has stays as it is.

## Rules

- No real bank, merchant or product marks anywhere in this repository. Merchants render as a monogram in a brand hue.
  A household may supply its own logo pack in a gitignored `logos/` folder, which the build embeds; the public demo
  ships none.
- The parody institutions in the portals (Westpaw, CommBark, Amewx, PING, PropertyMeow) get original wordmarks in the
  kit's type, never a lookalike of a real logo.
- The design language (Bricolage Grotesque and DM Sans, the violet, coral, teal and lime accents, the tokens in
  `src/style.css`) is settled; the kit extends it, nothing replaces it.
