# Evidence

Everything here is about fictional households. Each folder says how the run was set up before it says what happened.

| Folder | Question | Answer |
|---|---|---|
| `model-ladder/` | Can a model in a harness read a family's whole paper trail with no importer, and does the model matter? | Opus 5.5 tied 468 of 468 balances and landed within 0.03% of three-year totals for $4.58. Every model read every format; smaller models made more big meaning calls the other way. |
| `data-model-test/` | Does an established data model help the model load, or does a blank Sheet do as well? | A blank Sheet did as well, to the cent. The template's value is that every household has the same shape. |
| `move-in-test/` | When money is spread across a Drive, an inbox and notes, is the hard part reasoning or reach? | Reach. In one folder every model found all four planted gaps. Behind a search box, runs without the six-line coverage checklist missed a card statement that never arrived; runs with it found everything. |
| `page-test/` | Can the asks behind 35 versions of a real page be written down so a one-shot page meets them? | Yes. Without the 18-line bar Sonnet met 10 of 16 scored lines and Opus 12; with it, every model met all 16, Haiku for $0.25. |
| `guidance-test/` | Once the admin is done, does tax guidance over MCP change the advice? | Not the advice. With it every answer linked an ato.gov.au page and it stated FY26's figures; without it, it declined to state the current rate. |

`model-ladder/notes/` holds each model's own notes on what it found and what it was unsure of. `data-model-test/PROTOCOL.md` was written before any run and not changed after.

The families come from `standard/eval/` (family six is `heldout6`). The full write-up is `../FINDINGS.md`.
