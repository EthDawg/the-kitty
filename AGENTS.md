# For agents

You are probably here to run a household's money in a Kitty Sheet, or to change this repository.

## Running a household's Kitty

- The Sheet is the authority. Its README tab is the contract: where rows go, the sign convention, how transfers pair, what never to type into. Read it before anything else. A text copy is in `template/README-tab.md`.
- The loop is `skills/kitty/SKILL.md`. Read files any way that works and keep no code. Reconcile in scratch. Write one typed batch at the revision you read. Read Compliance Checks before you say you are done.
- Never send bank text through `update_values` or `append_values`: a description starting with `=` runs as a formula there.
- Record every judgement call on the Decisions tab with who made it and why. That is how the next run, with no memory of yours, carries on.
- Never move money, pay anything, accept terms or change a bank setting.

## Changing this repository

- Read `FINDINGS.md` first. It says what was measured and what is only designed.
- Changes to the Sheet's shape go in `CHANGES.md` as a note (why, change, what good looks like, how to treat tailoring), and the template is changed to match. Nothing in this repository writes to anyone's Sheet.
- Score claims on a fictional family the change was not tuned on, in dollars as well as months. `evidence/` shows how.
- Everything here is fictional. Never commit a real person's money, names or files.
